# PayMC — web

Донат-платформа для игровых серверов (Minecraft, Rust, GTA V RP, ARK, Unturned и ещё 11 игр): магазин, приём
платежей, мгновенная выдача в игре с трассировкой, ежедневные выплаты, чеки самозанятого, маркетинг внутри игры.

Это **фронтенд MVP**: продающий лендинг, личный кабинет владельца и витрина для игроков на детерминированных
демо-данных. Бэкенда нет — контракт данных описан в `src/lib/mock/types.ts`.

**Концепция продукта, исследование рынка и описание всех экранов — [docs/CONCEPT.md](docs/CONCEPT.md).**

## Запуск

```bash
pnpm install
pnpm dev
```

| Адрес | Что это |
|---|---|
| `/` | Лендинг с интерактивной песочницей доставки |
| `/dashboard` | Личный кабинет демо-проекта ArcticMC (⌘K — поиск и команды, G + буква — переходы) |
| `/s/arctic` | Витрина магазина глазами игрока |
| `/signup`, `/login`, `/onboarding` | Регистрация и первый запуск |
| `/design` | Дизайн-система: токены и компоненты |

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4 (стандартная палитра отключена — только токены
бренда), Radix UI, Recharts, Motion, cmdk. Шрифты: Geologica, Onest, JetBrains Mono.
