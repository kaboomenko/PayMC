# PayMC — web

Донат-платформа для игровых серверов (Minecraft, Rust, GTA V RP, ARK, Unturned и ещё 11 игр): магазин, приём
платежей, мгновенная выдача в игре с трассировкой, ежедневные выплаты, чеки самозанятого, маркетинг внутри игры.

Это **фронтенд MVP**: продающий лендинг, личный кабинет владельца и витрина для игроков на детерминированных
демо-данных. Бэкенда нет — контракт данных описан в `src/lib/mock/types.ts`.

**Концепция продукта, исследование рынка и описание всех экранов — [docs/CONCEPT.md](docs/CONCEPT.md).**

## Запуск

```bash
pnpm install
pnpm dev
```

| Адрес | Что это |
|---|---|
| `/` | Лендинг с интерактивной песочницей доставки |
| `/dashboard` | Личный кабинет демо-проекта ArcticMC (⌘K — поиск и команды, G + буква — переходы) |
| `/s/arctic` | Витрина магазина глазами игрока |
| `/signup`, `/login`, `/onboarding` | Регистрация и первый запуск |
| `/design` | Дизайн-система: токены и компоненты |

## Что посмотреть за 5 минут

1. **`/`** — в hero нажмите «Купить»: путь платежа до игрового чата с миллисекундами. Включите «Игрок офлайн»,
   смените игру, впишите свой ник. Ниже — трассы заказов, библиотека команд, калькулятор, переезд.
2. **`/dashboard`** — пульс проекта: KPI, «Требует внимания» (SkyBlock офлайн, сбой плагина на «Анархии»).
   Нажмите `Ctrl+K` и наберите `pfrfps` (это «заказы» в английской раскладке) или номер заказа.
3. **Заказы** → вкладка «Требуют внимания» → любой заказ: трасса выдачи, автоповторы, возврат, пакет для спора.
4. **Товары → Frost**: конструктор команд, библиотека шаблонов, «Проверить выдачу», проверка правил Minecraft.
5. **Кампании в игре → «Новая кампания»**: превью сообщения в чате, на экране, в боссбаре и Telegram.
6. **Финансы**: маршрут выплат с резервным банком, сплит команды, трекер лимита самозанятого.
7. **`/s/arctic`** — витрина глазами игрока: купите Frost с промокодом `WINTER25`.
8. **`/onboarding`** — запуск магазина за 5 шагов, включая переезд с другой площадки.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4 (стандартная палитра отключена — только токены
бренда), Radix UI, Recharts, Motion, cmdk. Шрифты: Geologica, Onest, JetBrains Mono.
