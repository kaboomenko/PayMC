# PayMC — концепция MVP сайта

> Лендинг + личный кабинет владельца + витрина для игроков. Документ описывает, **что** мы строим и **почему**;
> код в этом репозитории — кликабельная реализация этой концепции на демо-данных (бэкенда нет).
> Дата: 6 ноября 2026.

---

## 1. Суть

**PayMC — донат-платформа для игровых серверов**: владелец за вечер открывает магазин, игроки платят привычными
способами, покупка сама приходит в игру, деньги — владельцу каждый день.

Игры: Minecraft, Rust, GTA V RP (RAGE:MP, alt:V), ARK, Unturned, Garry's Mod, CS2, DayZ, SCUM, SA-MP/CRMP,
7 Days to Die, Project Zomboid; в бете — Valheim, Palworld, Terraria, Hytale.

**Позиционирование:** «Донат, который доходит». Двойной смысл, на котором держится весь продукт:

1. **Доходит до игрока** — выдача за доли секунды, а если сервер лёг или игрок офлайн — дождётся. Каждый шаг виден.
2. **Доходит до владельца** — выплаты каждый день в 12:00, резервный банк, деньги не лежат на счёте площадки.
3. **Растёт** — маркетинг там, где игроки: в чате, на экране, в Telegram, а не в почте.

## 4. Модель цены

- **Одна ставка 4,9 % — всё включено:** эквайринг, ежедневные выплаты, чеки (НПД и 54-ФЗ), выдача и трассировка,
  антифрод, кампании, A/B-тесты, команда и сплит.
- **Ступени по обороту — автоматически:** 3,9 % от 500 тыс ₽/мес, 2,9 % от 3 млн ₽/мес (индивидуально).
- **Без абонентки**, без платы за подключение и за выплаты по расписанию.
- По себестоимости: мгновенный вывод (+0,5 %), оплата с баланса телефона (комиссия оператора + 2 п.п.).
- Экономика: чекаут по умолчанию — СБП (≈0,7–1 % себестоимости), карты — ≈3,4–4,3 % с НДС; при доле СБП
  ~60 % смешанная себестоимость ≈2,1–2,4 % → валовая маржа ≈2,5 п.п. на ставке 4,9 %.

## 5. Правовая и платёжная основа (что обещаем на сайте)

- Деньги игроков проходят через банк-партнёр по схеме **мультирасчётов** — PayMC не держит деньги владельцев на своём
  счёте (снижает риски 115-ФЗ и блокировок).
- Живые способы оплаты: **СБП, Мир, SberPay, T-Pay, ЮMoney, баланс телефона**. Kaspi, ЕРИП, зарубежные карты —
  вторая фаза через партнёров в СНГ. Криптовалюта российским игрокам — нет. QIWI — нет (лицензия отозвана).
- Холд: **СБП — без холда**, карты — 24 ч, у новых магазинов — дольше; резерв на чарджбэки только по картам.
- **Чеки:** самозанятые — через партнёрский доступ «Мой налог» (чек в момент оплаты); ИП/ООО — облачная касса + ОФД.
- Подвал сайта: оператор, реквизиты, оферта для владельцев, правила для игроков, возвраты, политика ПДн (152-ФЗ),
  «данные хранятся в РФ». Логотипы — только реально работающих способов. Без значков сертификаций, которых нет.

### 6.3 Витрина для игроков `/s/arctic`

Шапка с онлайном и адресом сервера, значок «Проверено PayMC», ник игрока запоминается, цель месяца, «только что
купили», категории, складчины с прогрессом. Чекаут: подтверждение ника или подарок другу, промокод, способ оплаты
(недоступные — с пометкой «скоро»), почта для чека → QR СБП → живой статус выдачи «оплачено → на сервере → выдано».

### 6.4 Вход, регистрация и онбординг

`/login`, `/signup` — без лишнего, вход через Telegram/VK. `/onboarding` — 5 шагов: игра и проект → подключение
сервера (плагин или RCON, с живым ожиданием подключения) → товары из шаблонов **или переезд** с другой площадки →
выплаты и налоговый статус → готово (ссылка на магазин, тестовая покупка, чек-лист).

## 7. Ключевые сценарии

1. **Первый вечер.** Регистрация → выбор игры → `paymc connect pk_…` в консоли сервера → набор «Привилегии на
   LuckPerms» с ценами → ссылка на магазин в Telegram-канал. Цель — первый платёж за 10 минут.
2. **«Мне не выдали донат».** Модератор ищет ник в ⌘K → открывает заказ → видит трассу: «игрок офлайн — выдача при
   входе» или «плагин PlayerPoints не найден на сервере» → чинит конфиг → «Повторить выдачу». Игрок получает
   сообщение в чате.
3. **Сервер упал.** SkyBlock не на связи → задания копятся в очереди → владелец получает алерт в Telegram → после
   рестарта агент выполняет очередь сам. В «Обзоре» видно, что и сколько ждёт.
4. **Чарджбэк.** Банк оспаривает платёж → привилегия снимается автоматически → пакет доказательств уходит в банк →
   карта попадает в общий чёрный список — следующий платёж с неё отклонит антифрод на любом проекте PayMC.
5. **Вайп.** В календаре стоит вайп Анархии 1 декабря → за 2 часа анонс в Telegram и чате → в момент вайпа скидка
   20 % на 6 часов → кампания «Старт зимнего сезона» сообщает игрокам при входе.
6. **Выплата.** 12:00 — выплата за вчера делится 60/25/15 и уходит по СБП трём участникам; у каждого свой чек НПД.
   Основной банк не принял перевод → через 40 минут деньги ушли резервным маршрутом, это видно в истории.
7. **Переезд.** Импорт из другой площадки: товары, команды (неизвестные переменные подсвечены), промокоды,
   покупатели с остатком срока привилегий → подключение сервера → переключение ссылки на магазин.

## 8. Дизайн-система

**Принцип:** продукт должен выглядеть как сделанный людьми с вкусом и опытом, а не сгенерированный шаблон.

Запрещено: фиолетово-синие градиенты, градиентный текст, стекло и светящиеся пятна, сетка «иконка в цветном квадрате +
заголовок + абзац», эмодзи, фейковые логотипы и отзывы, одинаковые бенто-карточки, слова «революционный», «бесшовный»,
«на новый уровень», «мощный», центрирование всего подряд.

Вместо этого: реальные фрагменты интерфейса (трассы, консоли, чат игры, графики на демо-данных), асимметричная
вёрстка по левому краю, крупная типографика с плотным трекингом, моноширинные цифры, тонкие линии и слоистые
поверхности, движение только там, где оно объясняет (≤ 600 мс, с учётом `prefers-reduced-motion`).

| Токен | Значение |
|---|---|
| Поверхности | `#05070b` → `#0a0d14` → `#0e121b` → `#141a26` → `#1b2231` (синеватый почти-чёрный) |
| Линии | rgba(148,166,204) с прозрачностью 6 / 11 / 20 % |
| Текст | `#edf1f8`, `#b2bccd`, `#7c889d`, `#4d586c` (контраст проверен по WCAG/APCA) |
| Azure (основной синий) | шкала `#eef5ff` … `#0d1a3d`, кнопки — `#215fed` (белый текст 5,4 : 1) |
| Ice (голубой) | `#55cfff` — «живое», второй ряд графиков |
| Белый | главный CTA на лендинге |
| Статусы | ok `#3fd18f`, warn `#f3b84d`, bad `#f2616f` — только для состояний |
| Шрифты | Geologica (заголовки, ось «острота»), Onest (интерфейс, кириллица в приоритете), JetBrains Mono (цифры, команды, метки) |
| Радиусы | 4 / 6 / 8 / 10 / 14 px, не больше 18 |

Стандартная палитра Tailwind в проекте **отключена** — физически нельзя взять «чужой» цвет.
Витрина компонентов: `/design`.
